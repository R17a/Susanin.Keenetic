# Susanin Helper (Chrome/Edge/Yandex)

Попап-расширение: добавляет **текущий сайт** в списки `vpn_always` / `vpn_never`
через веб-панель Susanin.Keenetic. Четыре кнопки: «В always», «Из always»,
«В never», «Из never» — и строка, где сайт уже лежит.

## Установка

1. Откройте `chrome://extensions` (или `edge://extensions`, `browser://extensions`).
2. Включите **Режим разработчика**.
3. **Загрузить распакованное** → выберите папку `ext/susanin-helper` из репозитория.

Расширение не требует сборки и не публикуется в сторах — это локальный помощник.

## Настройка

В панели роутера (`/opt/susanin/etc/susanin.conf`) должны быть:

```
web_enable=1
web_listen=192.168.1.1
web_token=ВАШ_ТОКЕН
```

В попапе → **Настройки панели**:

- **URL** — `http://192.168.1.1:8087` (порт `web_port`, по умолчанию 8087);
- **Токен** — значение `web_token`;
- **Сохранить**, затем **Проверить связь** — покажет версию панели.

Токен хранится в `chrome.storage.local` (не синхронизируется между устройствами).

## Как работает

| Запрос | Назначение |
|---|---|
| `POST /api/list` (`list`, `op`, `value`) | добавить/убрать запись; заголовок `X-Auth-Token` |
| `GET /api/list?name=vpn_always\|vpn_never` | показать, где сайт уже лежит |
| `GET /api/status` | «Проверить связь», версия панели |

После правки панель шлёт агенту `SIGHUP`, списки перечитываются без рестарта.

## «Без www»

Галочка включена по умолчанию: для `www.example.com` в список уйдёт
`example.com`, а «Из …» снимет оба варианта. Снимите галочку, если нужен
ровно текущий хост.

## Ограничения

- Панель работает по **HTTP** и только в LAN — расширение открывает только
  частные подсети (`host_permissions` в `manifest.json`). Если панель на другой
  подсети, добавьте шаблон вида `http://172.20.*/*`.
- Если в `web_token` пусто, панель работает без токена (и предупреждает об этом);
  расширение просто не шлёт заголовок.
- Расширение не меняет `vpn_always.txt`/`vpn_never.txt` напрямую — только через
  API панели.
