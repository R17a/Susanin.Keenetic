# Установка/обновление НЕ перезаписывают уже существующий
# /opt/susanin/etc/vpn_never.txt — правьте его свободно. Новые записи из сборки
# при этом ДОПОЛНЯЮТ файл (merge; существующие строки не удаляются).
#
# Автодополнение из сборки отключается флагом запуска:
#     sh update.sh --keep-lists
# (или sh install.sh --keep-lists) — тогда не трогаются ни этот файл, ни
# vpn_always.txt.
#
# Формат: домен / *.домен / IPv4 / CIDR a.b.c.d/n, по одной записи на строку.
# '#' — комментарии. Поддомены можно указывать и отдельными строками: DNS не
# отдаёт списка «случайных» поддоменов, поэтому для сервисов с обычным DNS
# надёжнее явные имена, а не wildcard.
#
# Префикс '?' (мягкая запись) здесь НЕ поддерживается: строку «?домен» движок
# не разбирает как запись, она игнорируется. Мягкая запись имеет смысл только в
# vpn_always.txt — там она означает «напрямую, а в VPN агент уведёт сам, если
# прямой путь деградировал».
#
# Приоритет: этот список старше автообучения — адреса из него не попадают
# в ok/test и не маркируются для VPN; для них в цепочке SUSANIN стоит RETURN.
# Если зона есть и в vpn_always.txt, приоритет у этого списка (напрямую).
#

# «включён ли VPN» по адресу выхода, поэтому должен ходить напрямую. Набор собран
# по дампу трафика приложения. Также включён набор 1С-Битрикс — см. блок ниже.
# Файл при обновлении не перезаписывается, но может дополняться новыми записями
# из сборки (merge; существующие строки не удаляются) — правьте его свободно.
