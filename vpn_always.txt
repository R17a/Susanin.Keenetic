# vpn_always.txt — домены, которые ВСЕГДА идут через VPN (в обход автообучения).
# Поставляется с дистрибутивом.
#
# Состав намеренно узкий: только сервисы, которые отказывают пользователям из РФ
# (Anthropic/Claude, OpenAI/ChatGPT и их CDN). Остальное маршрутизируется
# автообучением: каждая лишняя запись здесь — это лишний резолв, пин и запись в
# ipset на каждом проходе, то есть работа главного цикла агента.
#
# Установка/обновление НЕ перезаписывают существующий
# /opt/susanin/etc/vpn_always.txt, но дополняют его новыми записями из сборки
# (merge; существующие строки не удаляются) — правьте его свободно.
# Автодополнение из сборки отключается флагом запуска:
#     sh update.sh --keep-lists
# (или sh install.sh --keep-lists). Тогда install/update не трогают ни
# vpn_always.txt, ни vpn_never.txt вообще.
#
# Лимит записей в файле — 512 (VA_MAXDOM), хвост сверх лимита молча
# игнорировался. Важное держите ближе к началу.
#
# Формат: домен / *.домен / IPv4 / CIDR a.b.c.d/n, по одной записи на строку.
# '#' — комментарии. Поддомены можно указывать и отдельными строками
# (api.example.com, www.example.com). IPv6 в v1 не поддерживается (только A).
#
# Префикс '?' делает запись МЯГКОЙ: по умолчанию трафик идёт напрямую, но если
# прямой путь деградировал (ТСПУ/DPI), агент сам уведёт адрес в VPN, а когда
# прямой оживёт — вернёт обратно. Отличие от жёсткой записи ровно в том, что
# мягкая не ставит пин в VPN заранее и не резолвится этим списком.
# Пример: ?bitrix24.ru   (для зоны — ?*.example.com)
#
# Демон резолвит A-записи жёстких доменов в susanin_ok_{tcp,udp}, CIDR — в
# susanin_ok_net; изменения подхватываются на лету.
